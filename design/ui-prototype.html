Quick Help

  • Left click to use current tool.
  • Use Build to place towers and auto-connect walls.
  • In Build, right click or press Esc to unlink the selected tower.
  • Right click or middle click and drag to pan.
  • Use WASD or the arrow keys to move around the map.
  • Shift/Ctrl/Cmd + click to multi-select in Select / Move.
  • Double-click an object to select every matching type, colour, and health.
  • Draw Hole: click vertices, then click the first vertex to close. Esc cancels.
  • Hold Ctrl to temporarily disable object and grid snapping.
  • Ctrl+C copies selection; left click places the ghost copy.
  • Save a selection under Custom Shapes to reuse it between maps and sessions.
  • Drag the blue rotation handle to rotate a selected group.
  • Drag a side or corner handle to scale; drag the dotted outline to move.
  • Draw one or more mirror axes, then use live mode or mirror a selection once.
  • In Select / Move, drag a mirror axis directly to reposition it; axes are never part of group selection.
  • Mouse wheel to zoom at cursor.

What changed, and why

The old editor kept every feature visible at once: two permanent sidebars, seven stacked panels, and a floating settings sheet. Nothing was hidden, so nothing had priority. This version keeps every feature and gives each one a home.

The canvas itself is unchanged. Rendering, selection handles, dragging, rotating and scaling all stay exactly as they are today. The drawing here is only a stand-in so the surrounding interface has something to sit around.

The moves

Tools became an icon railSeven full-width text buttons became a 52px rail with number shortcuts. Recovered: roughly 230px of the left sidebar.
Tool options follow the toolMirroring controls only exist while the Mirror tool is active. Tower health and team only exist in Build. Boundary presets only exist in Draw boundary. The old Mirroring, Map Shape and Defaults panels no longer exist.
Quick Help became a shortcut sheetSeventeen permanent bullet points, roughly a third of the right sidebar, are now one overlay on ?.
The right side is only the InspectorOne job: what is selected and what you can change about it. Grouped into Position, Appearance and Properties instead of a flat stack of labelled inputs.
Saved shapes got their own libraryThe old Custom Shapes panel became a flyout on L that holds nothing else, so saving and reusing a group is one place rather than two.
Settings became a real modalThe old panel floated over the canvas and mixed grid options with Export Map. Now five tabs, and file actions moved to the File menu where people look for them.
Feedback moved to where you lookThe status line sat at the bottom of the left sidebar, far from the cursor. It now runs along the bottom of the canvas with the snapping toggles, coordinates and zoom.
Steps that were buttons became automaticImporting a file that is not a Cosmowar map opens conversion on its own. Exporting runs the export check first instead of asking you to run it. Bomb site letters assign themselves in order rather than being typed. The Map menu had nothing left in it, so it is gone.

Visual system

One accent colour, used only for the active tool, primary actions and confirmations. One radius scale. Flat surfaces separated by hairlines instead of gradient-filled buttons and glowing panel borders. The body background lost its two coloured glows so the canvas is the brightest thing on screen.

Chakra Petch stays as the wordmark to keep the identity. Interface text moves to Geist and every number uses Geist Mono, so coordinates stop shifting width as you drag.

The Current view

The Current switch at the top loads the existing interface, built from the real markup and stylesheet so the comparison is honest rather than redrawn from memory. Both views share one canvas and one selection, so you can pick an object in one and flip to see how the other presents it.

In that view the canvas, the tool buttons, the selection panel, the status line, the cursor readout and the settings sheet are live. The remaining controls are inert.

Try it

Tools respond to 1 to 7. Click a tower, spawn or bomb site to load the Inspector. Drag to move it. Wheel zooms, right drag pans. ? opens shortcuts, L opens the library, G toggles the grid.

Draw hole shows the closing behaviour: place three vertices, then click the first one again.
